 SpaceSimulator

**Космический симулятор для визуализации гравитационного взаимодействия небесных тел**

##  Описание

**SpaceSimulator** — это интерактивное приложение для визуализации гравитационного взаимодействия между планетами, звёздами и астероидами. Программа позволяет пользователю:

- Добавлять различные небесные тела (планеты, звёзды, астероиды)
- Задавать их массу и наблюдать за движением
- Запускать физическую симуляцию с N-body гравитацией
- Изучать законы Кеплера и небесную механику в реальном времени

Приложение создано на языке Python с использованием библиотеки Pygame.

---

##  Функционал

### Основные возможности

| Функция | Описание |
|---------|----------|
| **Добавление объектов** | Выбор планеты, звезды или астероида через меню |
| **Настройка массы** | Ввод массы в массах Земли (планеты/астероиды) или в массах Солнца (звёзды) |
| **Размещение** | Клик ЛКМ по экрану для размещения объекта |
| **Удаление** | ПКМ по объекту для удаления |
| **Старт/Стоп** | Запуск и остановка физической симуляции |
| **Управление камерой** | Зажать ЛКМ на фоне и перемещать |
| **Масштабирование** | Колесо мыши и кнопки «+»/«-» |
| **Скорость симуляции** | Ползунок (0.1x – 1.0x) |

### Физические явления

| Явление | Описание |
|---------|----------|
| **N-body гравитация** | Все объекты притягиваются друг к другу по закону Ньютона |
| **Эллиптические орбиты** | Реалистичные вытянутые орбиты с эксцентриситетом |
| **Столкновения** | Поглощение массивными объектами менее массивных |
| **Сохранение импульса** | При столкновениях импульс сохраняется |
| **Вращение по часовой стрелке** | Все планеты вращаются в одном направлении |
| **Гибель Солнца** | Солнце может погибнуть при столкновении с более массивной звездой |

### Особенности астероидов

| Особенность | Описание |
|-------------|----------|
| **Маленький размер** | Астероиды в 2 раза меньше планет |
| **Вытянутая орбита** | Эксцентриситет 0.15 (более вытянутая, чем у планет) |
| **Не создают гравитацию** | Астероиды не влияют на другие объекты |
| **Разрушаются при столкновении** | Исчезают без поглощения |

### Интерфейс

| Элемент | Описание |
|---------|----------|
| **Мини-карта** | Показывает все объекты в уменьшенном масштабе |
| **Информационная панель** | При ЛКМ на объект открывается подробная информация |
| **Стартовый экран** | Кнопки «Играть», «Справка», «Описание» |
| **Всплывающие уведомления** | Оповещения о событиях (не более 3 одновременно) |
